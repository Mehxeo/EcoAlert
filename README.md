# EcoAlert 🌍

EcoAlert is a web app that shows real-time weather, air quality, and environmental data on an interactive map. Click anywhere or search for a location to get insights.

## Features

- 🌦️ Current weather and 7-day forecast
- 💨 Air quality info (PM2.5, PM10, CO, NO₂, etc.)
- 📍 Location search and click-to-select
- 🗺️ Map overlays (temperature, wind, pressure, etc.)
- 🌙 Light/dark mode toggle
- 🔄 Recenter to current location

## Getting Started

1. Clone this repo  
   `git clone https://github.com/your-username/ecoalert.git`

2. Open `map.html` in your browser  
   Or run locally with Python:  
   `python -m http.server`

## Tech Stack
- Python Flask
- JavaScript (Vanilla)
- Leaflet.js
- Open-Meteo & OpenWeatherMap APIs
